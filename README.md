# Сайт Риммы Сковородниковой

React + TypeScript + Vite, обычный CSS. Без бэкенда, без внешних скриптов, шрифты лежат в проекте.

## Запуск

```bash
npm install
npm run dev       # локально: http://localhost:5173
npm run build     # готовый сайт в папке dist/
npm run preview   # посмотреть собранную версию
```

## Где что менять

| Что | Где |
|---|---|
| Все тексты, контакты, пакеты, факты, отзывы, списки фото и видео | `src/data/content.ts` |
| Цвета, шрифты, отступы | `src/styles/global.css` (блок `:root` в начале) |
| Порядок секций | `src/App.tsx` |
| Фото | `public/media/photos/` |
| Видео и обложки | `public/media/video/` |
| Скриншоты отзывов | `public/media/reviews/` |

Компоненты (`src/components`, `src/sections`) тексты не содержат: менять их для обновления контента не нужно.

### Добавить фото

1. Положить файл в `public/media/photos/` (лучше `.webp` или `.jpg` до 1600 px по длинной стороне).
2. В `content.ts` добавить объект в `photos`:
   ```ts
   forumLipetsk: { src: 'media/photos/forum-lipetsk.webp', alt: 'Форум в Липецке', ratio: '4/5', pos: '50% 30%', caption: 'Форум, Липецк' },
   ```
   `pos` — кадрирование (`object-position`): первое число двигает кадр по горизонтали, второе по вертикали.
3. Использовать его в нужном месте: в `gallery`, `forum.photos`, `agency.photos` и т. д.

### Добавить или заменить видео

- Видео форума и ролик агентства уже размечены как заглушки: `videos.forum` и `videos.agency`. Впишите `src: 'media/video/имя.mp4'` (и `poster`), и заглушка сменится плеером.
- Внешнее видео (VK Видео, Rutube, YouTube): укажите `embed: 'https://…ссылка для встраивания…'` вместо `src`.
- Перед загрузкой большие ролики лучше сжать, например так:
  `ffmpeg -i in.mp4 -vf scale=720:-2 -c:v libx264 -crf 28 -preset slow -c:a aac -b:a 96k -movflags +faststart out.mp4`

### Добавить отзыв

Скриншот положить в `public/media/reviews/`, в `content.ts` добавить объект в `reviews`: повод, источник, цитата (дословно со скриншота), автор, дата. `featured: true` выделяет отзыв тёмной карточкой.

## Публикация на GitHub Pages

В `vite.config.ts` стоит `base: './'`, поэтому сайт работает из любой папки.

1. `npm run build`.
2. Залить содержимое `dist/` в репозиторий (ветка `gh-pages` или папка `docs/`) и включить Pages в настройках репозитория.

Можно и автоматически: GitHub Actions → шаблон «Static HTML» с путём `./dist` после шага `npm ci && npm run build`.

## Что уточнить у Риммы перед запуском

- Прямую ссылку на сообщество ВК «Антиквиз Липецк». Сейчас стоит ссылка на поиск ВК (`contacts.vk.href`).
- Видео и фото с форума (Липецк, Белгородская область), дату форума в Воронеже.
- Ролик об агентстве «За гранью» и больше информации о нём: команда, услуги, кейсы (`agency`).
- Согласие авторов отзывов на публикацию скриншотов с именами.
- Домен, если сайт будет не на github.io (тогда поправить `og:image` на полный адрес).
