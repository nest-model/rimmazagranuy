# Сюда кидаем фото и видео — код трогать не нужно

| Папка | Что появится на сайте |
|---|---|
| `gallery` | фото в блоке «Фото с праздников» |
| `forum` | фото в блоке форума (вместо заглушек) |
| `forum-video` | видео форума (берётся первый файл) |
| `agency` | фото в блоке «За гранью» |
| `agency-video` | ролик агентства (берётся первый файл) |
| `videos` | дополнительные видео в блоке «Видео» вверху сайта |

Фото: jpg, png, webp — любого размера, сайт сам уменьшит и сожмёт.
Видео: mp4 (лучше до 25 МБ — столько пропускает загрузка через сайт GitHub).
Порядок — по имени файла: `01.jpg`, `02.jpg`… Название видео на сайте = имя файла (`Свадьба 03.07.mp4` → «Свадьба 03.07»).
Удалить фото с сайта = удалить файл из папки.
